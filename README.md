# بلا نت | BLA NET — Flutter starter

This is the first UI milestone for the BLA NET Android/iOS app:
- Purple + pink visual identity
- Distinctive B mark
- Phone-number sign-in screen (UI only)
- Home/chat list screen with sample conversations
- Navigation between sign-in and chats

## Run
1. Install Flutter SDK and Android Studio / Xcode.
2. In this folder run: `flutter create .`
3. Run: `flutter pub get`
4. Run: `flutter run`

## Important
Phone sign-in is currently a UI prototype. Real SMS verification and live messaging
are not connected yet. The next milestone is Firebase setup (Authentication,
Cloud Firestore, and Storage), which requires creating a Firebase project and adding
its platform configuration files. Never put private service credentials in source control.instance_type: linux_x2
